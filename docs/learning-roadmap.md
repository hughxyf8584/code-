# 学习路线：Python、AI 与 EPC 工程管理

路线围绕一个持续扩展的实践问题展开：怎样把施工进度、质量状态和风险信息变成可核验、能辅助现场管理的分析结果。

## 阶段 1：Python 基础与工程数据

**学习内容**

- Python 基本语法、函数、模块、异常和文件路径。
- CSV、日期、百分数和缺失值的处理。
- 数据粒度、主键、单位、数据字典与输入校验。

**实践产出**

定义周度进度数据结构：报告日期、区块、工作项、计划百分比和实际百分比。使用合成数据明确字段、约束和偏差口径。

## 阶段 2：确定性分析

**学习内容**

- 使用 pandas 读取、筛选和分组汇总。
- 用函数把“计划、实际、偏差”的计算规则写清楚。
- 了解均值、加权平均、方差、相关性等统计概念，判断哪些统计方式适合工程数据。

**实践产出**

生成按区块与工作项展开的偏差表。只有在权重定义经过确认后，才计算总体加权进度，避免把简单平均误当成项目总体完成率。

## 阶段 3：可视化与报告

**学习内容**

- 使用 Plotly 对比计划与实际趋势。
- 展示落后区块、关键活动和数据缺口。
- 将图表导出为可分享的 HTML；后续再评估 Excel 或 PDF 输出。

**实践产出**

形成一份可重复生成的周度光伏进度分析报告，并清楚标注数据日期、数据来源、口径和限制。

## 阶段 4：AI、RAG、Agent 与 MCP

**学习内容**

- 先理解大语言模型的能力边界和结构化提示。
- 用 RAG 检索获准使用的项目程序、规范或管理模板，并保留来源引用。
- 学习 Agent 的任务分解、工具调用、人工确认点和失败处理。
- 以只读、最小权限方式探索 MCP 与本地分析工具的连接。

**实践产出**

让 AI 根据已校验的指标草拟解释或检索相关程序条款；进度数值仍由可追溯的程序计算，外部写操作须有明确授权和人工确认。

## 每个阶段的完成标准

- 可以用自己的话解释数据口径和计算规则。
- 能从输入追溯到输出，不依赖隐藏的手工步骤。
- 能指出数据质量问题、假设和结论适用范围。
- 工具输出能帮助现场或管理团队采取具体行动。
